
这行定义 mod 的父路径
module github.com/mattermost/mattermost/server/v8

并不是和物理目录完全一致.

这是 Go Modules 的“虚拟路径”机制
1. Go Modules 的主版本号后缀
当 go.mod 里的 module 名是 github.com/mattermost/mattermost/server/v8，v8 是主版本号，不是实际的目录。
你的本地目录结构依然是 server/config，不需要有 v8 目录。
2. Go 如何解析
Go 在构建和导入时，会自动把 v8 识别为 module 的主版本号，而不是目录。
只要 go.mod 里 module 名是 github.com/mattermost/mattermost/server/v8，
那么 import "github.com/mattermost/mattermost/server/v8/config" 实际会去找 server/config 目录下的代码。
