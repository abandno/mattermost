我来详细解释 **Emotion** 和 **JSS** 这两种 CSS-in-JS 解决方案的区别：

## Emotion vs JSS 详细对比

### 1. **基本概念**

**JSS (JavaScript Style Sheets)：**
- 将 CSS 转换为 JavaScript 对象
- 运行时生成样式
- 支持 CSS 的所有特性

**Emotion：**
- 更现代的 CSS-in-JS 解决方案
- 支持字符串和对象语法
- 更好的性能和开发体验

### 2. **语法对比**

**JSS 语法：**
```typescript
// @material-ui v4 使用 JSS
import { makeStyles } from '@material-ui/core/styles';

const useStyles = makeStyles((theme) => ({
  root: {
    backgroundColor: theme.palette.background.paper,
    padding: theme.spacing(2),
    '&:hover': {
      backgroundColor: theme.palette.action.hover,
    },
  },
  button: {
    margin: theme.spacing(1),
    '& .MuiButton-label': {
      color: 'red',
    },
  },
}));

// 使用
const MyComponent = () => {
  const classes = useStyles();
  return <div className={classes.root}>Content</div>;
};
```

**Emotion 语法：**
```typescript
// @mui/material v5 使用 Emotion
import { styled } from '@mui/material/styles';

const StyledDiv = styled('div')(({ theme }) => ({
  backgroundColor: theme.palette.background.paper,
  padding: theme.spacing(2),
  '&:hover': {
    backgroundColor: theme.palette.action.hover,
  },
}));

// 或者使用对象语法
const StyledButton = styled(Button)(({ theme }) => ({
  margin: theme.spacing(1),
  '& .MuiButton-label': {
    color: 'red',
  },
}));

// 使用
const MyComponent = () => {
  return <StyledDiv>Content</StyledDiv>;
};
```

### 3. **性能对比**

| 特性 | JSS | Emotion |
|------|-----|---------|
| **运行时性能** | 较慢 | 更快 |
| **包大小** | 较大 | 较小 |
| **缓存机制** | 基础 | 更智能 |
| **SSR 支持** | 需要额外配置 | 原生支持 |

### 4. **开发体验**

**JSS 开发体验：**
```typescript
// 需要记住特殊的语法
const useStyles = makeStyles((theme) => ({
  root: {
    // 嵌套选择器语法特殊
    '& .child': {
      color: 'red',
    },
    // 伪类选择器
    '&:hover': {
      backgroundColor: 'blue',
    },
  },
}));
```

**Emotion 开发体验：**
```typescript
// 更接近原生 CSS 的语法
const StyledComponent = styled('div')(({ theme }) => ({
  // 更直观的嵌套
  '.child': {
    color: 'red',
  },
  // 伪类选择器
  '&:hover': {
    backgroundColor: 'blue',
  },
  // 支持媒体查询
  '@media (max-width: 600px)': {
    padding: theme.spacing(1),
  },
}));
```

### 5. **主题集成**

**JSS 主题集成：**
```typescript
import { createTheme, ThemeProvider } from '@material-ui/core/styles';

const theme = createTheme({
  palette: {
    primary: {
      main: '#1976d2',
    },
  },
});

const useStyles = makeStyles((theme) => ({
  root: {
    color: theme.palette.primary.main,
    spacing: theme.spacing(2),
  },
}));
```

**Emotion 主题集成：**
```typescript
import { createTheme, ThemeProvider } from '@mui/material/styles';

const theme = createTheme({
  palette: {
    primary: {
      main: '#1976d2',
    },
  },
});

const StyledComponent = styled('div')(({ theme }) => ({
  color: theme.palette.primary.main,
  padding: theme.spacing(2),
}));
```

### 6. **动态样式**

**JSS 动态样式：**
```typescript
const useStyles = makeStyles((theme) => ({
  dynamic: (props) => ({
    backgroundColor: props.isActive ? 'green' : 'red',
    padding: props.size === 'large' ? theme.spacing(3) : theme.spacing(1),
  }),
}));

const MyComponent = ({ isActive, size }) => {
  const classes = useStyles({ isActive, size });
  return <div className={classes.dynamic}>Content</div>;
};
```

**Emotion 动态样式：**
```typescript
const StyledComponent = styled('div')<{ isActive: boolean; size: string }>(
  ({ theme, isActive, size }) => ({
    backgroundColor: isActive ? 'green' : 'red',
    padding: size === 'large' ? theme.spacing(3) : theme.spacing(1),
  })
);

const MyComponent = ({ isActive, size }) => {
  return <StyledComponent isActive={isActive} size={size}>Content</StyledComponent>;
};
```

### 8. **迁移建议**

**从 JSS 迁移到 Emotion：**

1. **更新依赖：**
```bash
npm uninstall @material-ui/core @material-ui/styles
npm install @mui/material @emotion/react @emotion/styled
```

2. **更新导入：**
```typescript
// 旧版本
import { makeStyles } from '@material-ui/core/styles';

// 新版本
import { styled } from '@mui/material/styles';
```

3. **重构样式：**
```typescript
// 旧版本 JSS
const useStyles = makeStyles((theme) => ({
  root: {
    padding: theme.spacing(2),
  },
}));

// 新版本 Emotion
const StyledComponent = styled('div')(({ theme }) => ({
  padding: theme.spacing(2),
}));
```
