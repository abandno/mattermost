Mattermost 项目中有多个 Client4 实现，它们有不同的用途：
1. mattermost-redux/client (推荐)
用途：Redux 集成的客户端，专门为前端应用设计
特点：
与 Redux store 集成
自动处理认证和会话
支持 Redux 的异步 action
在 Mattermost Web 应用中使用最广泛
2. @mattermost/client
用途：独立的客户端库
特点：
不依赖 Redux
适合独立应用或 Node.js 环境
更轻量级
3. @mattermost/client/src/client4
用途：内部源码文件
特点：
直接导入源码，不稳定
可能在未来版本中改变
不推荐在生产环境使用
4. components/suggestion/...
用途：特定组件的客户端
特点：
为特定功能定制
不是通用的 API 客户端
