## 总结

聊天窗消息列表的数据获取流程是：
1. **Redux store** 存储所有消息数据
2. **选择器** 从 store 中获取特定频道的消息列表
3. **虚拟化列表组件** 渲染消息列表
4. **PostComponent** 渲染单条消息
5. **QuotedPostDisplay** 显示引用消息（我们新增的功能）

当服务端返回包含 `qrid`/`qpid` 字段的消息时，我们的组件会自动从 Redux store 中获取被引用的消息并显示在消息上方。

export class Client4 {
    // 获取频道消息
    async getPosts(channelId: string, page = 0, perPage = 60): Promise<PostList> {
        return this.doFetch(
            `${this.getPostsRoute(channelId)}?page=${page}&per_page=${perPage}`,
            {method: 'get'}
        );
    }

    // 创建消息
    async createPost(post: Post): Promise<Post> {
        return this.doFetch(

            {method: 'post', body: JSON.stringify(post)}

    }
