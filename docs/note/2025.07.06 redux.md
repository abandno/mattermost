useSelector

订阅 Store 变化​​：useSelector 会订阅 Redux Store，当 Store 中的状态发生变化时，它会执行传入的选择器函数（即回调函数 state => state.someValue），检查返回的值是否与之前的选择结果不同。
​​浅比较（默认）​​：默认情况下，useSelector 使用 ​​引用比较（===）​​ 来判断状态是否变化。如果选择器返回的对象引用未变（即使内部属性变化），组件不会重新渲染。
const value = useSelector(state => state.someObject); // 若 someObject 引用未变，即使内部属性变化，也不会触发渲染
