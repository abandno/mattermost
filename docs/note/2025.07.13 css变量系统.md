
## cssVars 方法 原理介绍

> `import cssVars from 'css-vars-ponyfill'`
> webapp/channels/src/utils/utils.tsx:478, cssVars 方法


`cssVars` 是一个 **CSS 变量 (Custom Properties) 的 Polyfill**，它允许在不支持原生 CSS 变量的浏览器（如 IE11）中模拟使用 CSS 自定义属性。

---

### 🧠 原理简介

`cssVars` 通过以下步骤实现对 CSS 变量的支持：

#### 1. **解析样式表**
- 遍历文档中的所有 `<style>` 和 `<link rel="stylesheet">` 元素。
- 提取其中的 CSS 文本，并识别出 `:root` 或其他选择器中定义的变量：
  ```css
  :root {
    --primary-color: #007bff;
  }
  ```

#### 2. **变量替换**
- 将 CSS 中使用的变量（如 `color: var(--primary-color)`）替换为最终计算后的颜色值。
- 如果变量有 fallback 值（如 `var(--missing, red)`），则使用 fallback。

#### 3. **注入新样式**
- 创建一个新的 `<style>` 标签，将处理后的 CSS 插入页面中。
- 这样即使浏览器不支持原生 CSS 变量，也能渲染正确的样式。

#### 4. **监听 DOM 变化（可选）**
- 如果启用配置项如 `watch: true`，`cssVars` 会监听 DOM 的变化（新增样式标签等），并自动重新处理。

---

### ✅ 示例说明

```ts
import cssVars from 'css-vars-ponyfill';

cssVars({
  variables: {
    'primary-color': '#007bff',
    'secondary-color': '#6c757d',
  },
});
```

会被转换为：

```css
:root {
  --primary-color: #007bff;
  --secondary-color: #6c757d;
}
```

然后在你的 CSS 中：

```css
.button {
  background-color: var(--primary-color);
}
```

会被 polyfill 处理成：

```css
.button {
  background-color: #007bff;
}
```

---

### 🛠️ 主要配置选项

| 配置项         | 说明 |
|----------------|------|
| `variables`    | 手动指定变量对象 `{ '--key': 'value' }` |
| `onlyLegacy`   | 是否只在不支持 CSS 变量的浏览器运行（默认 `true`） |
| `preserve`     | 是否保留原始 CSS 变量代码 |
| `updateDOM`    | 是否更新 `<html>` 或 `<body>` 上的样式 |
| `watch`        | 是否监听 DOM 新增的样式标签 |

---

### 🔍 适用场景

- 支持旧版浏览器（如 IE11）
- 动态主题切换（通过更新 `variables` 实现）
- 不想用 Sass/Less 等预处理器，但又希望用 CSS 变量提升可维护性

---

### ⚠️ 注意事项

- 性能：每次调用都会重新解析和插入样式，频繁调用可能影响性能。
- 作用域：只能处理全局作用域下的变量，不能像原生那样嵌套使用。
- 异步加载样式时需手动触发更新（例如使用 `window.CSSVariables.update()`）
