
# 二开后, 代码开源, 但是部署的服务收费赚钱可以吗?

根据 Mattermost 的许可证情况，**可以**这样做，但需要注意一些细节：

## AGPL v3.0 许可证允许的商业模式

### ✅ **完全合法的做法**：

1. **开源代码 + 收费服务**
   - 修改后的源代码必须开源（AGPL要求）
   - 但可以对部署的服务收费
   - 这是典型的"开源软件即服务"(Open Source SaaS)模式

2. **具体可以做的**：
   - 提供托管服务收费
   - 技术支持和咨询收费  
   - 定制开发收费
   - 企业级功能收费
   - 数据迁移、培训等服务收费

### 📋 **必须遵守的义务**：

1. **源代码开源**：
   - 所有修改必须以AGPL v3.0开源
   - 用户有权获取完整源代码
   - 包括服务器端的所有修改

2. **版权声明**：
   - 保留原始版权信息
   - 标明你的修改部分

3. **许可证传递**：
   - 衍生作品也必须使用AGPL v3.0

## 成功案例参考

许多公司都采用这种模式：
- **GitLab** (开源版本 + 付费托管服务)
- **MongoDB** (开源数据库 + Atlas云服务)
- **Nextcloud** (开源文件同步 + 企业服务)

````markdown path=your-mattermost-fork/README.md mode=EDIT
我们提供：
- 托管部署服务
- 技术支持
- 定制开发
- 企业培训

````

**结论**：这是完全合法且常见的商业模式。只要确保代码开源，你就可以自由地对服务收费盈利。
