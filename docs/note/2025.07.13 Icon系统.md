## Mattermost 图标系统详解

### 1. **两种不同的图标系统**

Mattermost 中确实存在两种不同的图标系统：

#### **A. Font Awesome 图标系统** (`fa fa-xx`)
```tsx
// 标准的 Font Awesome 用法
<i className='fa fa-search' />
<i className='fa fa-plus' />
<i className='fa fa-warning' />
<i className='fa fa-angle-down' />
<i className='fa fa-check' />
<i className='fa fa-refresh' />
<i className='fa fa-angle-left' />
<i className='fa fa-spinner fa-pulse fa-2x' />
```

#### **B. Mattermost 自定义图标系统** (`icon icon-xx`)
```tsx
// Mattermost 自定义图标系统
<i className='icon icon-close' />
<i className='icon icon-chevron-down' />
<i className='icon icon-chevron-left' />
<i className='icon icon-chevron-right' />
<i className='icon icon-star' />
<i className='icon icon-star-outline' />
```

### 2. **Font Awesome 图标系统** (`fa fa-xx`)

**特点：**
- 使用标准的 Font Awesome 类名格式
- 通过 `@import '~font-awesome/css/font-awesome.css'` 引入
- 基于 Font Awesome 字体文件

**CSS 定义：**
```scss
.fa {
    &.fa-1x {
        font-size: 1.6rem;
    }
}

%font-awesome {
    display: inline-block;
    font: normal normal normal 14px/1 FontAwesome;
    font-size: inherit;
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
    text-rendering: auto;
    transform: translate(0, 0);
}
```

### 3. **Mattermost 自定义图标系统** (`icon icon-xx`)

**特点：**
- Mattermost 自己定义的图标系统
- 使用 `icon` 基础类 + 具体图标名称
- 可能有自己的字体文件或 SVG 实现

**CSS 定义：**
```scss
.icon {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    font-size: 18px;
}

.icon-10 { font-size: 12px; }
.icon-12 { font-size: 14.4px; }
.icon-16 { font-size: 18px; }
.icon-20 { font-size: 24px; }
.icon-28 { font-size: 31.2px; }
.icon-32 { font-size: 36px; }
.icon-40 { font-size: 48px; }
.icon-52 { font-size: 60px; }
.icon-64 { font-size: 72px; }
```

### 4. **两种系统的区别**

| 特性 | Font Awesome (`fa fa-xx`) | Mattermost 自定义 (`icon icon-xx`) |
|------|---------------------------|-----------------------------------|
| 类名格式 | `fa fa-iconname` | `icon icon-iconname` |
| 来源 | Font Awesome 库 | Mattermost 自定义 |
| 字体文件 | Font Awesome 字体 | 可能是自定义字体或 SVG |
| 图标数量 | 大量标准图标 | 有限的特定图标 |
| 使用场景 | 通用图标 | Mattermost 特定功能图标 |

### 5. **实际使用示例**

**Font Awesome 图标：**
```tsx
// 搜索图标
<i className='fa fa-search' />

// 警告图标
<i className='fa fa-warning' />

// 加载动画
<i className='fa fa-spinner fa-pulse fa-2x' />
```

**Mattermost 自定义图标：**
```tsx
// 关闭图标
<i className='icon icon-close' />

// 下拉箭头
<i className='icon icon-chevron-down' />

// 收藏星标
<i className='icon icon-star' />
```

### 6. **为什么会有两套系统？**

1. **历史原因**：Mattermost 早期使用 Font Awesome，后来开发了自己的图标系统
2. **定制需求**：自定义图标系统更适合 Mattermost 的特定设计需求
3. **性能考虑**：自定义图标可能更轻量，只包含需要的图标
4. **设计一致性**：自定义图标系统确保设计风格统一

### 7. **发展趋势**

从代码中可以看出，Mattermost 正在逐步迁移到 `@mattermost/compass-icons`：

```tsx
// 现代方式
import {CloseIcon, SearchIcon} from '@mattermost/compass-icons/components';
<CloseIcon size={18} color={'currentColor'} />
```
