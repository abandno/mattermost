


## sql, args, err := query.ToSql(), args 怎么来的?

```go
 Where(sq.And{
    sq.Eq{"RootId": rootId},  // 这里会生成参数
    sq.Eq{"DeleteAt": 0},     // 这里会生成参数
}).Suffix(")"),

Where(sq.And{
    sq.Or{
        sq.Eq{"p.Id": rootId},      // 这里会生成参数
        sq.Eq{"p.RootId": rootId},  // 这里会生成参数
    },
    sq.Eq{"p.DeleteAt": 0},        // 这里会生成参数
})
```

squirrel 的定位是单纯的构造sql和收集占位参数.
具体查询, 它不关心.
