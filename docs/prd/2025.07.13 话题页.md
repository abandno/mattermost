

新增另一种类型的首页, 估计叫做"话题首页"吧, 重点突出"话题".
类似知乎, stackoverflow, 百度贴吧 等社区论坛. 但是, 我要加上关键关键的功能:
1. 帖子的讨论回复是实时的, 类似IM.
2. 帖子内容、评论、回复，和聊天窗口的内容是联动的. 即，聊天窗新增了的，帖子里就能看到；同样帖子里新增的，聊天窗口也能看到；
3. 聊天和帖子能够自由来回跳转。

## 功能1：话题首页

1. mattermost 聊天窗中的回复串、引用串，组成了帖子的内容。串的收条消息作为帖子的话题，后续消息作为评论，后续消息的引用，作为其在话题页中的评论的回复。
2. 首页展示该用户能看到的频道中的帖子。两个列表：1）最热，即回复数最多的；2）最新，即最新回复时间最新的。


查讨论串头消息
```sql
SELECT *
FROM (
    -- 子查询1：从 threads 关联中取 replycount < 1000 的前10条 posts
    (
        SELECT p.*, t.replycount, 'threads' as thread_type
        FROM posts p
        JOIN threads t ON p.id = t.postid
        WHERE p.deleteat = 0 AND t.replycount < 1000
        ORDER BY t.replycount DESC
        LIMIT 10
    )
    UNION ALL
    -- 子查询2：从 replythreads 关联中取 replycount < 1000 的前10条 posts
    (
        SELECT p.*, t.replycount, 'replythreads' as thread_type
        FROM posts p
        JOIN replythreads t ON p.id = t.postid
        WHERE t.replycount < 1000
        ORDER BY t.replycount DESC
        LIMIT 10
    )
) AS combined_results
ORDER BY replycount DESC
LIMIT 10;
```

优化后
```sql
select * from 
(
SELECT *
FROM (
    (
        SELECT postid, replycount, 'threads' as thread_type
        FROM threads t
        WHERE deleteat = 0 AND replycount < 1000
        ORDER BY replycount DESC
        LIMIT 10
    )
    UNION ALL
    (
        SELECT postid, replycount, 'replythreads' as thread_type
        FROM replythreads
        WHERE replycount < 1000
        ORDER BY replycount DESC
        LIMIT 10
    )
) AS combined_threads
ORDER BY combined_threads.replycount DESC
LIMIT 10
) as final_threads
join posts on final_threads.postid = posts.id
```

### 帖子翻页逻辑

```go
// 下一页(next): 按 replycount 降序, 且小于 After (非空非0), 取前 N 个
	// 上一页(prev): 按 replycount 升序, 且大于 Before (非空非0), 取前 N 个, 最后返回的结果要翻转下
	// 第一页(first): 按 replycount 降序, 取前 N 个
	// 最后一页(last): 按 replycount 升序, 取前 N 个, 最后返回的结果要翻转下
	// 下一页如果没有了, 降级返回最后一页; 上一页如果没有了, 降级返回第一页. 即在有数据的情况下, 避免返回给用空list

	// 两种threads一起排序取top, 然后关联出posts
	threadQuery := `
SELECT * FROM 
(
	SELECT *
	FROM (
		(
			SELECT postid, replycount, lastreplyat, participants, 'threads' as thread_type
			FROM threads t
			WHERE deleteat = 0 AND replycount < 1000
			ORDER BY replycount DESC
			LIMIT 10
		)
		UNION ALL
		(
			SELECT postid, replycount, lastreplyat, participants, 'replythreads' as thread_type
			FROM replythreads
			WHERE replycount < 1000
			ORDER BY replycount DESC
			LIMIT 10
		)
	) AS combined_threads
	ORDER BY combined_threads.replycount DESC
	LIMIT 10
) as final_threads
JOIN posts on final_threads.postid = posts.id`
```
