
增加一张表, 表达post的回复关系.

CREATE TABLE "public"."postreply" (
  "postid" varchar(26) COLLATE "pg_catalog"."default" NOT NULL,
  "pid" varchar(26) COLLATE "pg_catalog"."default",
  "rid" varchar(26) COLLATE "pg_catalog"."default",
  "rcount" int4,
  "createat" int8,
  "updateat" int8,
  "deleteat" int8
)
;

该造已有的 threads 表, 增加一个类型标识, 1 为讨论串, 即原有的, 也是默认值; 2 为我新增引用串.

这个表的记录相当于就是话题的标题, 定位对应的post, 及方便按回复数排序.

原有 post 加的 qrid 和 qpid 不要了. sql迁移记录不要.

重写引用功能:
1. 发送引用消息时, postreply 新增一条引用关系. postid是当前消息id, pid 是被引用的消息id, rid 是串的根消息id.
2. pid在postreply对应的行(无则新增), rcount(回复数)加1.
3. pid如果根, 则在 threads 表无则新增一条记录, 类型是 2. replycount加1, lastreplyat 更新.
